Get started

Install once.
Build anywhere.

Clyx requires a stable Rust toolchain. Generated projects use CMake 3.16+ and a C or C++ compiler.

Read the prerequisites →
Install with Cargo
$ cargo install clyx
Create your first project
$ clyx new hello --language cpp \
  --standard c++20 --tests --git
